# 📐 Key Business Metrics

## Cancellation Rate

![Cancellation Rate Formula](images/Formula1.png)

Measures the percentage of total reservations that were cancelled.

\[
Cancellation\ Rate =
\frac{Cancelled\ Bookings}{Total\ Bookings}
\times 100
\]

---

## Estimated Revenue

\[
Estimated\ Revenue =
\sum_{i=1}^{N}R_i
\]

Represents the estimated revenue generated from successful hotel reservations.

---

## Lost Revenue

\[
Lost\ Revenue =
\sum_{i:C_i=1}V_i
\]

Estimates the potential revenue associated with cancelled reservations.

---

## Average Daily Rate

![ADR Formula](images/Formula2.png)

\[
ADR =
\frac{1}{N}
\sum_{i=1}^{N}ADR_i
\]

Shows the average room rate generated across reservations.

---

## Repeat Guest Rate

\[
Repeat\ Guest\ Rate =
\frac{Repeat\ Guest\ Bookings}{Total\ Bookings}
\times 100
\]

Measures the percentage of bookings generated by returning customers.

# 🗄 SQL Analysis

SQL was used to explore the hotel booking data before visualisation in Power BI.

Example:

```sql
SELECT
    hotel,
    COUNT(*) AS total_bookings,
    SUM(
        CASE
            WHEN is_canceled = 1 THEN 1
            ELSE 0
        END
    ) AS cancelled_bookings,
    ROUND(
        100.0 *
        SUM(
            CASE
                WHEN is_canceled = 1 THEN 1
                ELSE 0
            END
        ) / COUNT(*),
        2
    ) AS cancellation_rate
FROM hotel_bookings
GROUP BY hotel;
